- 📺 B站“纯问号”弹幕监控系统 (Bili-??-Monitor)

  > **"当满屏都是 '?' 的时候，我就知道这个视频不简单。"**

  ## 📖 项目简介
  
  这是一个**专门寻找 B 站“名场面”和“迷惑行为”**的自动化猎手。它不关心视频有多少硬币，只关心视频里有多少**弹幕**，以及有多少观众在**扣问号**。
  
  通过 **24 小时全自动巡逻** B 站各大分区（动画、游戏、鬼畜等），它会自动捕获高热度视频，精准分析“纯问号”弹幕占比，并生成一个赛博朋克风格的实时看板。

  链接：https://list.hicatalpa.cn/ 挂了就挂了吧，Cloudflared Tunnel忒不稳定了

  ## ✨ 核心特性 (Cool Features)
  
  ### 1. 🧪 “全员懵逼”检测器
  程序不仅数弹幕，还会把每一条弹幕拆开看。只有内容为纯粹的 `?` 或 `？` 时才会被计入。
  * **浓度榜**：你可以一眼看到那些让 50% 的观众都打出问号的离谱视频。
  
  ### 2. 🛡️ 弹性准入漏斗 (Smart Funnel)
  为了不漏掉好视频，程序内置了一套“势利眼”算法：
  * **超级巨星**：弹幕 > 1500 条？请进请进，不管你浓度多少。
  * **潜力股**：弹幕 > 1200 条？哪怕少一点，只要你的问号浓度 > 15%，也给你发“破格录取通知书”。
  * **杂鱼**：弹幕少又没梗？直接 `Drop`，日志都不会记录你。
  
  ### 3. 🏛️ 赛博博物馆 (The Archive)
  * **冷热分离**：活跃库只保留最新、最热的数据，保证网页秒开。
  * **永不丢失**：当一个好视频因为时间久了被“清理”出活跃库时，它会被压缩存入博物馆。
  * **双重计数**：网页顶部实时显示 **“🏛️ 馆藏总量”** 和 **“💾 活跃展示”**，记录你的每一次狩猎。
  
  ### 4. 📝 “神评”直达
  不需要点进视频，程序会自动把点赞最高的那条**热评**抓回来，展示在卡片底部。
  *(配合问号食用，风味更佳)*
  
  ### 5. 🎨 终极看板 (Web Dashboard)
  * **瀑布流布局**：CSS Grid + 自适应高度，卡片像瀑布一样自然流淌，顶部绝对对齐。
  * **沉浸体验**：暗黑模式，UP主主页直达，封面懒加载。

  ## 🚀 快速开始
  
  ### 1. 环境准备
  确保你的 Python 环境已准备好（推荐 Python 3.8+）：
  ```bash
  pip install requests brotli user-agent
  
- ### 2. 个性化配置

  在 `bili_monitor.py` 头部可以微调你的猎手：

  Python

  ```
  # 狩猎标准
  HARD_THRESHOLD = 1500       # 硬门槛
  SOFT_THRESHOLD = 1200       # 软门槛
  RATIO_THRESHOLD = 15.0      # 浓度及格线
  
  # 永生机制
  MAX_DB_SIZE = 5000          # 活跃库最大容量
  TARGET_REGIONS = { ... }    # 巡逻分区
  ```

  ### 3. 启动

  Bash

  ```
  python bili_monitor.py
  ```

  程序启动后会开启 Web 服务器，并开始在各大分区巡逻。

  ### 4. 访问看板

  - **内网访问**：打开浏览器输入 `http://localhost:8000`
  - **外网访问**：推荐使用 **Cloudflare Tunnel**（配置 `http2` 协议以获得最佳稳定性）。

  ## 🌐 远程访问指南 (Cloudflare Tunnel)

  如果你想在外面也能随时查看家里的看板，推荐使用 Cloudflare Tunnel。

  **config.yml 参考配置：**

  YAML

  ```
  tunnel: <你的Tunnel名>
  credentials-file: <你的凭证路径>.json
  protocol: http2  # [关键] 强制使用 http2 协议，解决国内连接不稳定的问题
  
  ingress:
    - hostname: list.你的域名.com
      service: http://localhost:8000
    - service: http_status:404
  ```

  ## ⚠️ 注意事项

  1. **Cookies**：建议在同目录下放一个 `cookies.json` 以获取更完整的弹幕数据和高清封面。
  2. **系统时间**：程序会校验视频发布时间。如果你的系统时间设定在未来（如 2026 年），请确保 Python 的 SSL 证书验证正常（v17+ 已恢复标准验证）。**(笑点解析之Gemini不知道自己活在2026年)**
